## Convenções desta documentação

- Escrita em português do Brasil, em linguagem direta. Termos de código ficam em `monoespaçado`.
- **Dinheiro** sempre em centavos inteiros; **datas** de lançamento no formato `AAAA-MM-DD`.
- Os limites citados (tamanhos, quantidades, prazos) são os do código da versão 1.0. Quando um
  limite mudar, atualize o documento no mesmo pull request.
